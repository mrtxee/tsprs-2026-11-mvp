## ADR-01. Система координат симулятора РЛС

| Поле    | Значение                                                               |
| ------- | ---------------------------------------------------------------------- |
| Статус  | принят                                                                 |
| Дата    | 2026-11-10                                                             |
| Формат  | ADR — запись архитектурного решения                                    |
| Область | виртуальный эмулятор РЛС, симуляция, карта, цели, кольца, зоны, снимки |

### Контекст

Реальной радиолокационной системы (РЛС) нет и не планируется: приложение — виртуальный эмулятор РЛС. Необходимо согласовано хранить и представлять координаты тайлов карты, колец точности, целей.

| Элемент        | Хранение координат           | Представление                                                             |
| -------------- | ---------------------------- | ------------------------------------------------------------------------- |
| Тайлы          | локальные файлы              | через мета данные тайла: размер в метрах + X/Y верхнего левого угла тайла |
| Кольца         | X/Y центра в метрах + радиус | окружности и секторы в локальных метрах                                   |
| Объекты (цели) | X/Y в метрах                 | точка на карте; широта и долгота через конвертацию                        |

### Альтернативы

| Критерий сравнения                   | СК-42                     | Web Mercator           | Локальная 2D система координат | WGS84                  |
| ------------------------------------ | ------------------------- | ---------------------- | ------------------------------ | ---------------------- |
| Математика трекинга, зоны, дальности | трансформации и конверсии | искажения проекции     | напрямую                       | градусы, нужен переход |
| Масштабируемость                     | привязана к географии     | через формулы проекции | напрямую                       | привязана к географии  |
| Эмулируемые физические эффекты       | через пересчёт            | через пересчёт         | напрямую                       | через пересчёт         |
| **Итог**                             | —                         | —                      | **принята как основная**       | —                      |

### Решение

Основная рабочая система — локальная двумерная декартова система координат. Все измерения и события моделируются на плоскости: две координаты X/Y в метрах.

### Обоснование

- Реальной РЛС нет: виртуальный эмулятор не требует СК-42 и геодезических трансформаций.
- Вся математика трекинга проста и без искажений.
- Дальности, азимуты и скорости получаются напрямую, без конверсий.

### Последствия

- Плюс: ядро симуляции без проекций и конверсий, простая математика.
- Минус: не подходит для работы с реальной РЛС
