## Функциональность системы

| Поле             | Значение                                                            |
| ---------------- | ------------------------------------------------------------------- |
| Название         | Тренажёр-симулятор применения радиолокационных систем               |
| Краткое название | ТСПРС                                                               |
| Стек             | Rust + TypeScript                                                   |
| Характер         | сетевое многопользовательское приложение, работающее через Интернет |

### Описание системы

ТСПРС (тренажёр-симулятор применения радиолокационных систем) имитирует рабочее место оператора радиолокационной системы (РЛС) на виртуальном эмуляторе. Реальная РЛС не планируется.

Задача оператора системы — двойным нажатием левой кнопки мыши по иконке объекта определить наибольшее число объектов типа «БВС».
