**Функциональные требования к ПО**

**1. Общие функциональные требования**

1. ПО должно обеспечивать выполнение следующих функциональных возможностей:

	- Cимуляция работы интерфейса типовой РЛС с имитацией основных настроек или элементов управления системой
	- Отображение интерактивной карты радиолокационной системы с возможностями персональных настроек;
	- Генерация и отображение на карте объектов, обнаруженных РЛС, с указанием их основных параметров
	- Интерактивное взаимодействие пользователя с обнаруженными объектами в формате тренировок
	- Зонирование карты, позволяющее точнее определять и отслеживать цели;
	- Авторизация пользователей и разграничение прав доступа для двух типовых ролей
	- Архив событий, позволяющий делать снимок экрана ПО при обнаружении тревожных событий.

**2 Требования к интерфейсу основного меню ПО**

1. Для начала работы симулятора программа должна требовать пройти авторизацию в меню авторизации.
2. После запуска ПО должно появиться основное меню программы. Во время работы ПО, он должен состоять из трех разделов:
	- **Режим «Тренировка»**
	- **Профиль.** Переключение в раздел с основного меню происходит при помощи кнопки «Профиль». Раздел содержит в себе информацию о пользователе, роль, историю тренировок и статистику. В этом разделе пользователь может изменить пароль или выйти из системы.
	- **Настройки.** Переключение в раздел с основного меню происходит при помощи кнопки «Настройки». Раздел содержит в себе возможность изменение базовых настроек ПО – графика, громкость звука и др., а также настройки пользователей и прав доступа для пользователей с ролью «Администратор».

**3. Требования к режиму «Тренировка»**

1. Режим тренировки запускается с экрана основного меню ПО с помощью кнопки «Режим «Тренировка»».
2. Перед началом сеанса появляется всплывающее окно «Настройки тренировки», позволяющее задать ограничение по времени, количество генерируемых объектов и других параметров предстоящей тренировки.
3. После сохранения настроек на экране пользователя запускается интерфейс режима тренировки, состоящий из:

	- Модуля «Карта»;
	- Элементов управления симуляцией.

4. Основная задача пользователя в рамках тренировки за ограниченное количество времени правильно определить наибольшее количество объектов типа «БВС» из числа регулярно генерируемых на карте объектов всех типов.
5. Определением объекта как объекта типа «БВС» системой должно считаться двойное нажатие по его иконке на карте левой кнопкой мыши.
6. После завершения сеанса тренировки на экране должно появиться окно с результатами тренировки.
7. Система должна иметь возможность сохранять результаты проведенных тренировок и по запросу пользователя отражать их в разделе «Профиль».

**3.1. Описание модуля «Карта»**

- В целях симуляции работы типового интерфейса РЛС во время режима тренировки интерфейс ПО должен отображать модуль «Карта», содержащий следующие компоненты:
- карта местности;
- зоны обнаружения и игнорирования;
- радарные кольца;
- обнаруженные объекты.

**3.1.1. Карта местности**

Карта местности служит географической основой для визуализации данных с РЛС, обеспечивая оператора контекстом для анализа целей. Карта должна быть интерактивной и адаптивной. Должна быть возможность передвигать карту и изменять ее масштаб.

**3.1.2. Радарные кольца**

Радарные кольца – это фиксированное визуальное отображение дистанции работы РЛС на карте, которое дает возможность быстро оценить отдаленность обнаруживаемых объектов. На карте они должны быть отображены в виде окружностей или секторов, расходящихся от местоположения РЛС.

Каждое кольцо соответствует определенной дистанции обнаружения:

до 1000 метров – Близкая дистанция – область уверенного обнаружения даже малозаметных целей;

до 3000 метров – Средняя дистанция – территория, где РЛС видит крупные цели, но с меньшей точностью;

до 7000 метров – Дальняя дистанция – максимальная дистанция, на которой станция может засечь объекты.

**3.1.3. Зоны обнаружения и игнорирования**
- Cимуляция работы интерфейса типовой РЛС с имитацией основных настроек или элементов управления системой
	- Отображение интерактивной карты радиолокационной системы с возможностями персональных настроек
	- Генерация и отображение на карте объектов, обнаруженных РЛС, с указанием их основных параметров;
	- Интерактивное взаимодействие пользователя с обнаруженными объектами в формате тренировок;
	- Зонирование карты позволяющее точнее определять и отслеживать цели;
	- Авторизация пользователей и разграничение прав доступа для двух типовых ролей
	- Архив событий, позволяющий делать снимок экрана ПО при обнаружении тревожных событий.
1. В ПО должен быть предусмотрен компонент «Зоны». Он предназначен для отображения границ охраняемой зоны в рамках действия радиолокационной станции.

Необходимо реализовать два типа зон:

- зона обнаружения - предназначена для отображения целей внутри полигона с последующим уведомлением о проникновении с помощью визуального уведомления или звукового сигнала;
- зона игнорирования - используется для скрытия целей внутри зоны обнаружения. При этом все уведомления об объектах, появляющихся в зоне игнорирования, не создаются.

**3.1.4. Обнаруженные объекты**

1. При запуске симуляции в приложении должны генерироваться и отображаться на карте обнаруженные объекты.
2. Визуализация обнаруженных объектов представляет из себя идентичную (вне зависимости от типа объекта) точку. У каждого движущегося объекта на карте должны быть графически изображены направление движения и траектория, если эти функции включены в настройках.
3. На карте может появляться суммарно до 20 точек разных типов объектов.
4. Необходимо разработать алгоритм поведения на карте движущихся объектов двух типов:
	- объекты типа «БВС»;
	- объекты типа «Птицы».

При генерации объектов на карте объекты разных типов должны быть отличимые друг от друга по следующим критериям поведения:

|                                    | Тип объекта «БВС»                             | Тип объекта «Птицы»                                  |
| ---------------------------------- | --------------------------------------------- | ---------------------------------------------------- |
| Дистанция обнаружения объекта РЛС  | Максимальная или средняя дистанция            | Любая дистанция обнаружения                          |
| Траектория движения<br><br>объекта | Прямая траектория полета, в направлении к РЛС | Кривая траектория полета, в любом направлении от РЛС |
| Скорость движения объекта          | От 25 до 35 метров в секунду                  | От 2 до 10 метров в секунду                          |
| Время присутствия объекта на РЛИ   | Более 10 секунд                               | Не более 10 секунд                                   |

Место появления объекта на карте, скорость движения и дистанция обнаружения между каждым отдельным объектом одного типа должны различаться, но при этом значения должны соответствовать вышеперечисленным требованиям.

1. При наведении курсора на объект должно появляться окно с описанием параметров объекта:
	- скорость движения;
	- долгота;
	- широта.

**3.2. Описание элементов управления симуляцией**

В целях симуляции работы типового интерфейса РЛС во время режима тренировки интерфейс ПО должен содержать следующие элементы:
- кнопка вызова меню настроек симуляции;
- кнопка вызова меню центра уведомлений;
- кнопка паузы;
- панель текущей даты и времени;
- панель позиции;
- панель компаса.

**3.2.1. Кнопка вызова меню настроек симуляции**

При нажатии на кнопку на экране должно появляться меню настроек симуляции со следующими блоками:
- настройка карты;
- настройка зон;
- выход из режима «Тренировка».

**3.2.2. Кнопка вызова меню центра уведомлений**

Вызов меню центра уведомлений должен быть реализован по нажатию на соответствующую кнопку.

**3.2.3. Кнопка паузы**

При нажатии на кнопку текущий сеанс режима «Тренировка» приостанавливается и возобновляется при повторном нажатии на кнопку.

**3.2.4. Панель текущей даты и времени**

Панель должна иметь информационный характер, информируя пользователя о текущей дате и времени, в котором работает ПО.

**3.2.5. Панель позиции**

Предназначена для мгновенного переключения перспективы карты в нужную позицию.

Нажатие на иконку «Дом» должно возвращать пользователя в домашнюю позицию, которая задается в меню «Настройка карты».

**3.2.6. Панель компаса**

Компас — это виджет на главном экране симуляции, который должен возвращать карту с ориентацией на север (север вверху) по клику левой кнопки мыши.

**3.3. Авторизация и настройка пользователей**

Меню авторизации появляется при включении ПО. Для входа в программу нужно заполнить логин и пароль программы.
