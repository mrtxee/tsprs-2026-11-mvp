## ТСПРС

Тренажёр-симулятор применения радиолокационных систем: сетевое многопользовательское веб-приложение для подготовки оператора РЛС. Реальной радиолокационной станции нет — работа идёт с виртуальным эмулятором.

- [Хранение данных системы](docs/05-данные-и-хранилища.md) — схема данных, связи, системы хранения.
